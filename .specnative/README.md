# Docs

Documentacion del framework SpecNative Development.

## Contenido

- [`CLI.md`](./CLI.md):
  referencia del CLI de SpecNative, comandos disponibles, campos TOML
  y uso avanzado para proyectos que quieren validacion automatica.
- [`integrations/github-project.toml.example`](./integrations/github-project.toml.example):
  configuracion de ejemplo para generar planes de exportacion a GitHub Projects.

## Separacion importante

Esta carpeta contiene documentacion del framework, no del proyecto.

- Los comandos del proyecto real van en `spec-native/COMMANDS.md`.
- La arquitectura y convenciones del proyecto van en `spec-native/`.
- Los procedimientos de ejecucion van en `spec-native/workflows/`.
