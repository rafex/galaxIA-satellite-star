# Architecture Artifacts

Cada componente, límite, flujo o restricción relevante usa un archivo
`ARCH-XXXX-<slug>.md`. `../ARCHITECTURE.md` es solo el índice.

```toml
+++
doctype = "architecture"
id = "ARCH-0001"
title = "Authentication boundary"
status = "active"
related_decisions = ["DEC-0001"]
related_specs = ["SPEC-AUTH-0001"]
tags = ["component/authentication", "concern/security"]
+++
```
