# Intake

Entrada de ideas y solicitudes de trabajo que todavia no tienen una spec o
criterios suficientes para ser tareas ejecutables.

`IDEAS.md` conserva elementos en estado `triaged`. Antes de implementarlos,
un agente o desarrollador debe asociarlos a una iniciativa, crear o actualizar
la spec y derivar una tarea en `../tasks/` con criterio de cierre y validacion.

Usa `capture_backlog_item()` del MCP o los comandos `spec-backlog-add` de
Claude Code, OpenCode o Codex. No copies elementos de intake a un tablero:
el tablero solo se genera desde tareas canónicas.
