# Convention Artifacts

Cada regla que debe mantenerse en el tiempo usa un archivo
`CONV-XXXX-<slug>.md`. `../CONVENTIONS.md` es solo el índice.

```toml
+++
doctype = "convention"
id = "CONV-0001"
title = "Tests before implementation"
status = "active"
related_architecture = ["ARCH-0001"]
related_decisions = []
tags = ["concern/testing", "workflow/implementation"]
+++
```
